# AIXEM Validation

Validation material is separated by authority and lifecycle:

- [`releases/`](releases/README.md) contains immutable human-readable release reports and implementation matrices.
- [`evidence/`](evidence/README.md) contains machine-bound evidence, requirement records, retained reviews, and repeated-run artifacts.
- Registered conformance corpora are entered through [Hierarchical Project Corpus 1](corpus/hierarchical-project-1/README.md) and [Reference Viewer Corpus 1](corpus/reference-viewer-1/README.md).
- Retained agent suites are entered through [Agent Evaluation 1](agent-evals/README.md), [Agent Evaluation 2](agent-evals-2/README.md), and [Agent Evaluation 3](agent-evals-3/README.md). Their local documentation and task files belong to those suites.
- `reports/` retains machine-readable historical JSON result paths for compatibility; human narratives no longer live there.

A report describes what was observed. It does not define circuit, renderer, Viewer, or agent-authoring authority.
