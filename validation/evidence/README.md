# Validation Evidence

This tree retains release evidence, requirement records, review records, repeated-run summaries, screenshots, and immutable baseline inventories. File locations may be bound into schemas, tests, manifests, or historical digests and therefore are not reorganized merely for visual consistency.

Human-readable release summaries are indexed under [`../releases/`](../releases/README.md). Machine evidence remains subordinate to the canonical requirement and validator that names it.
