# AIXEM Reusable Library

This tree is the canonical project-level home for newly authored reusable component libraries and symbol assets.

```text
library/electronics/
library/architecture/
```

Only these first-level domains are centrally controlled. Reuse an accurate existing lower namespace before creating the minimum new lower-kebab hierarchy.

Start with the [Create a Library Part guide](../docs/authoring/guides/create-library-part.md). The normative location, naming, provenance, semantic-identity, compatibility, and legacy-repair rules are owned by the [Library Layout and Part Integrity Contract](../docs/specifications/components/library-layout-contract.md). Example and validation fixture trees are not the default destination for reusable project parts.
