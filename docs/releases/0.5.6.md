# AIXEM 0.5.6 Live-Agent Cold-Start Authoring

AIXEM 0.5.6 turns the 0.5.5 closed authoring loop into a provider-neutral cold-start evaluation boundary. It can now compile an incomplete isolated stage, launch a declared external subprocess, retain observable behavior without private reasoning, score the actual final workspace using evaluator-only semantic invariants, and bind every terminal result into immutable evidence.

## Added

- Agent Task Contract 1 and route-authority resolver;
- Cold-Start Stage Contract 1 and deterministic sanitized reference pack;
- Live Executor Protocol 1 generic subprocess adapter;
- secret-name inheritance without secret-value serialization;
- Observation Event Contract 1 JSONL stream with no-CoT enforcement;
- Evaluation Invariant Contract 1 semantic scorer;
- Live Run Evidence 1 and Attempt Set 1 denominator integrity;
- `tools/live_agent_authoring.py` stage/execute/score/aggregate CLI;
- `tools/run_agent_evals_3.py` Tier A and optional Tier B runner;
- L001-L012 cold-start corpus with seven creation and five repair tasks;
- conformance tests for stage isolation, target leakage, executor proof, bounds, redaction, observation, scoring, retention, and claim gates.

## Preserved

0.5.6 does not replace `.aixem`, `.aixlayout.json`, `.aixsym.json`, `.aixlib.json`, project manifests, Viewer contracts, deterministic renderer output, Diagnostic Contract 1, Change-Set 1, or Authoring Run Record 1. Existing `prepare/check/close` remains the mutation and closure truth.

## Deliberately Not Added

- provider SDK dependencies in core;
- a proprietary agent runtime;
- an automatic source repairer in the evaluator;
- completed answer fixtures in cold-start stages;
- private chain-of-thought capture;
- a Structured Editor or transaction-command language;
- claims of arbitrary autonomous circuit design.

## Evidence Status in This Package

Tier A deterministic protocol conformance is executed and retained. No external AI executor was available or supplied in the build environment, so Tier B remains explicitly not executed with zero attempts and no authorized live claim. This package therefore demonstrates an implementation-complete, truth-preserving live harness while retaining the external Tier B execution gate as pending environmental evidence.

The exact state is published in:

- `validation/agent-evals-3/results/tier-a-results.json`;
- `validation/agent-evals-3/results/tier-b-status.json`;
- `validation/agent-evals-3/results/summary.json`.

## Compatibility

All additions are backward-compatible and reside in agent execution, validation, documentation, and evidence layers. Existing circuit-language and Viewer formats are unchanged.
