# AIXEM 0.5.5

## Release Objective

AIXEM 0.5.5 turns the existing route-first authoring guidance, validators, deterministic renderer, and Reference Viewer into an evidence-backed authoring loop. An agent can prepare a bounded task, edit existing authoritative formats, receive stable diagnostics, identify the smallest owner and remediation route, prove its file scope, repair locally, render deterministically, and close with Authoring Run Record 1.

## Delivered Contracts

- Agent Diagnostic Contract 1 and a complete P0 stable-code registry;
- Authoring Change-Set Contract 1 with objective before/after digest and JSON Pointer evidence;
- Authoring Execution Contract 1 with `PREPARED -> CHECK -> REPAIR -> CLOSE` state control;
- Authoring Run Record 1 with deterministic per-iteration and final closure evidence;
- backward-compatible route write-scope and remediation metadata;
- vendor-neutral `tools/agent_authoring.py prepare/check/close` harness;
- generated-output edit, wrong-authority edit, unsafe-path, stalled-loop, and oscillation rejection;
- Agent Evaluation 2 A001-A012 deterministic Tier A corpus;
- explicit Tier A replay versus Tier B live external-agent claim separation.

## Compatibility Boundary

AIXEM 0.5.5 does not introduce a new circuit language or change `.aixem`, `.aixsym.json`, `.aixlib.json`, `aixlayout/1`, `aixlayout/2`, `aixproj/1`, or `aixproj/2`. Diagnostics, change sets, execution packets, and run records are derived evidence only. The 0.5.4 Reference Viewer remains read-only, and protected SVG/resolved-scene/project-scene products remain byte-stable for equivalent locked inputs.

## Evaluation Truth

Tier A is deterministic harness/replay evidence and is mandatory. Tier B is a separate cold-start live external-agent mode. This release reports Tier B as not executed unless retained executor evidence proves otherwise; it does not convert fixture or replay success into a live-agent claim.

## Verification Evidence

Release closure uses three passes: contract/authority closure; repair-loop/scope behavior; and full regression/evaluation/claims/integrity. Evidence includes A001-A012 results, requirement traceability, protected render hashes, repository tests, legacy corpora, Viewer and hierarchical corpora, deterministic build outputs, and archive verification.

## Non-Goals

This release does not add a GUI editor, Viewer authoring controls, automatic patch synthesis, a new router, simulation, PCB/Gerber generation, vendor import/export, cloud collaboration, an agent daemon, a database-backed workspace, or autonomous arbitrary circuit design.
