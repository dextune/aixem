AIXEM 0.5.2

Documents the evidence-backed symbol expressiveness release, static 2D block profile, multi-unit boundary, and three-cycle verification.

AIXEM 0.5.2#

Document ID: AIXEM-RELEASE-052-001
Status: Informative
Version: 1.0

Release Objective#

AIXEM 0.5.2 is an expressiveness-conformance release. It proves the range of the existing AI-authorable symbol model before considering format growth.

Delivered Evidence#

  • 24 mandatory S-Core cases;
  • five S-Extended complex cases;
  • one isolated multi-unit semantic probe;
  • six Static 2D Block Profile cases;
  • one batch harness using the existing production renderer;
  • schema, binding, port, field, grid, lead-coincidence, geometry, determinism, approved-digest, and structured-review checks;
  • per-case SVG, resolved scene, render manifest, geometry signature, and performance observations;
  • capability and primitive-usage matrices;
  • agent route and cookbook integration for nearest-proven-pattern retrieval;
  • three complete release verification cycles, each covering representability, authoring/visual quality, and regression/claim integrity.

Results#

The release publishes the actual machine-readable results rather than embedding an unconditional claim in this note.

Expected release tiers after closure are:

  • S-Core: PASS;
  • S-Extended: PASS;
  • B2D: PASS;
  • MU: NOT_SUPPORTED, independently and honestly reported.

MU remains unsupported because the current model does not provide independently placeable unit presentations sharing one semantic component identity. A graphically complete large FPGA symbol does not change that semantic result.

Conservative Changes#

No new symbol primitive, symbol top-level field, parameter model, variant model, or multi-unit syntax was added.

Corpus visual inspection found one F3 renderer defect: internal dimension labels inherited an unsuitable SVG text size. The renderer now emits an explicit deterministic dimension-label style, and B005 plus a dedicated regression test protect the correction.

Compatibility Boundary#

AIXEM 0.5.2 does not claim native KiCad, OrCAD, DWG, DXF, or AutoCAD Dynamic Block compatibility. The release proves only the published AIXEM-owned conformance tiers against the recorded source and renderer digests.
