AIXEM 0.5.4

Documents Reference Viewer Contract 1, distinct Viewer and Workbench profiles, qualified browser behavior, security, accessibility, and three-pass release evidence.

AIXEM 0.5.4#

Release Objective#

AIXEM 0.5.4 replaces the loosely specified HTML consumption layer with Reference Viewer Contract 1 and a distinct Review Workbench profile. The release preserves valid 0.5.3 semantic, layout, project, resolved-scene, SVG, and routing authority while making browser behavior versioned, qualified, read-only, deterministic, offline, and executable as conformance evidence.

Delivered Contracts#

  • deterministic schema-validated Viewer Model 1 derived from resolved renderer evidence;
  • strict read-only viewer.html Reference Viewer profile;
  • distinct read-only workbench.html diagnostics/provenance profile;
  • qualified sheet, entity, local-net, interface, and project-net identities;
  • normalized Sheet, Overview, and Composite behavior;
  • deterministic search, inspector, sheet-scoped layers, and per-view viewport state;
  • keyboard operation, visible focus, semantic control state, and narrow-layout drawers;
  • self-contained CSP-constrained HTML with inert authored text and zero network requests;
  • V001-V018 browser/security/accessibility/determinism corpus.

Compatibility Boundary#

AIXEM 0.5.4 does not revise .aixem, .aixsym, .aixlib, aixlayout/1, aixlayout/2, aixproj/1, or aixproj/2. Existing leaf SVG, resolved-scene, project Overview, Composite, and resolved-project-scene products remain protected renderer evidence. Viewer Model 1 is an adapter and does not redefine those formats.

The output filenames remain viewer.html and workbench.html, but their meanings are now explicit and distinct. The former is the primary viewing surface; the latter adds engineering evidence. Neither is an editor.

Verification Evidence#

Release closure records three passes: contract/authority/structure; browser behavior/security/operability; and regression/determinism/documentation/claims. Evidence entry points include the Reference Viewer corpus results, pass records under validation/evidence/pass-01 through pass-03, the final validation report, release manifest, and deterministic package verification.

Non-Goals#

This release does not add component placement editing, wire or route editing, project-net/hierarchy editing, save/write-back, undo/redo, collaboration, plugins, remote project loading, PCB/Gerber viewing, waveform viewing, or vendor editor emulation.
